# 发布流程（v1.1.0）

## 一、发布前必须确认

| 检查项 | 说明 |
| --- | --- |
| 云函数重新部署 | `cloudfunctions/login`、`cloudfunctions/room` 都要右键「上传并部署：云端安装依赖」。**room 本次改动很大（新增 leave 移交房主、submitScore、avatarUrls 临时链接），不部署会直接报「未知操作」** |
| 云环境 ID | `app.js` 中 `env: 'cloud1-6gd9msfpc3b53edf'` 必须是正式环境 |
| 数据库集合 | 云开发控制台需存在 `rooms` 集合；权限建议设为「仅管理端可读写」（客户端全部走云函数） |
| 云存储权限 | `avatars/` 目录权限建议「仅创建者可读」，头像由云函数换临时链接下发 |
| 隐私保护指引 | mp 后台「设置 → 服务内容声明 → 用户隐私保护指引」需声明：头像（相册/相机）、上传图片、剪切板（复制房号）。未声明时线上调用 `chooseAvatar` / `setClipboardData` 会失败 |
| 类目 | 建议选「工具 → 效率」等普通类目，**避免选到「棋牌」类目**（棋牌类需要额外资质/版号，会被驳回） |
| 包体 | 已忽略测试数据 `database_export-*.json`、样式备份 `room_backup.wxss`、说明文档，主包很小 |

## 二、上传代码

1. 微信开发者工具打开项目根目录 `wx_xcx`（appid: `wx99e76f2c0508a6df`）
2. 先本地「编译」跑一遍：开房 → 另一台设备/另一个微信号进房 → 双方互相记分 → 退出房间，确认分数与房主移交正常
3. 点击右上角「上传」：
   - 版本号：`1.1.0`
   - 项目备注：`v1.1.0 头像云端化 + 计分/轮询优化 + 房主移交修复`（详细说明见 CHANGELOG.md）

## 三、提交审核与发布

1. mp.weixin.qq.com → 管理 → 版本管理 → 开发版本 → 「提交审核」
2. 审核说明可填：
   - 功能：棋牌/聚会计分工具，扫描或输入 4 位房号加入房间，点击他人头像记分
   - 头像昵称：使用微信「头像昵称填写能力」自主设置，仅用于房间内身份展示
   - 测试路径：首页 → 我要开房 → 复制房号；另一个账号 → 输入房号进房
3. 审核通过后点「发布」（可选全量发布/分阶段发布）

## 四、回滚

- 线上异常：版本管理 → 选择旧版本「版本回退」
- 云函数异常：云开发控制台 → 云函数 → 版本管理 → 回滚到上一版本
